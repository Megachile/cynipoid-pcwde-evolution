# Supplement domain and outgroup-screen summary

`scripts/tables/build_table_s2.py` writes `table_s2/candidate/data/domain_summary.tsv` as the shared fact table for the reader outgroup table, supplement prose tokens, and `numbers.json`. The output is built from the pinned ordinary origin-domain FASTAs and family membership, the B-lectin screen FASTA, the Figure S4 GH30_3 and PI-PLC-X unaligned and trimmed domain FASTAs, the accepted 49-genome source panel, and the same built copy table used for Figure 1. The producer receipt records SHA256 for each input and output.

Each row is a family. Ordinary-family focal and outgroup counts are domain units from the accepted origin set. Their bacterial/eukaryotic screen counts are the corresponding domain membership groups. The B-lectin tree outgroup count remains one source protein, while screen counts are domain hits by taxon from the pinned screen FASTA. GH30_3 and PI-PLC-X tree counts are unique FASTA identifiers; each trimmed and unaligned set must have identical identifiers. Their median trimmed length is the median number of non-gap amino acids. Focal genomes with an occurrence are distinct retained genome species among Figure S4 focal domain identifiers; transcriptome-only and unretained species are excluded, and the accepted *Eubothrus centaureae* name replaces the historical *Isocolus centaureae* label. No screen threshold or sequence membership is changed.

The reader table shows one combined screen-hits column (bacteria; eukaryotes). The intermediate retains bacterial, plant, fungus, metazoan and rotifer counts for prose tokens. The full 49-genome accepted-copy inventory is generated from the same copy table and placed in the data deposit as `data/accepted_copy_counts.tsv`.
