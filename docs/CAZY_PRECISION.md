# CAZy percentile precision

`build_cazy_ranks.py` computes each primary rank once using `rank_full`, the same calculation used by the legacy `rank` serializer. `primary_ecami_precision.tsv` exposes the unrounded percentile as a Python float round-trip decimal; existing two-decimal TSVs are unchanged. The reference consists of native eCAMI groups, with focal groups excluded as in the existing analysis. A nonzero focal count has midrank `1 + above + tied/2` and percentile `100 * (reference_n + 1 - midrank) / reference_n`; an empty reference gives 100. An absent focal count has no percentile. Units are percentile points (0–100), not rates.

`build_cazy_lineage_summary.py` joins all 576 species/family/route rows, validates their legacy serialization, and emits `lineage_precision.tsv`: all five reader lineages, three families and three existing routes. It takes the median over family-present genomes within each lineage and route, with genome/present counts recording the cohort denominator. The existing lineage authority defines the 48 cynipoid reader genomes and excludes the other 16 reference species. The existing four-group summaries remain unchanged.

`build_cazy_rank_table.py` joins the largest-group precision rows to all 15 reader rows with matching cohort counts and emits `Table_S14_precision.tsv`. Its input/output SHA256 receipt records the exact same-build intermediate. Make runs rank, lineage summary, reader table, then renderer in that order. The renderer checks unique complete joins and formats the supplied value to one decimal; it does not reconstruct ranks, choose routes or compute medians. E. primus GH5_2 is 39.94845360824742, displayed 39.9; the legacy scientific value remains 39.95. Existing scientific table schemas and numbers.json values are preserved.
