# Figure S4 full-protein domain architecture

The 246 retained tree tips map to 239 distinct full-length protein sequences. This is a display-only annotation. Tree membership, alignments, topology and support are unchanged. The complete tip mapping, deduplicated FASTA and HMMER hit table are retained under `repository_inputs/analysis/s4_architecture/`: the committed `scripts/figures/accessory_domain_trees/build_architecture.py --mapping ... --fasta ... --domtbl ...` reads them and regenerates the architecture table. The figure reads the checksum-pinned `repository_inputs/figures/accessory_domain_trees/architecture.tsv`.

The input sequences are frozen from the full-length GH30_3 and PI-PLC-X reference sets and the accepted beta-unit protein set; only identical amino-acid strings were deduplicated, and each of the 246 tree tips retains a mapping. The Actinoplanes awajinensis PI-PLC-X tip is mapped to the 1,202-aa full-length WP_067703811.1 source protein, not its 95-aa tree domain. I_centaureae is mapped to its 396-aa full-length protein; the historical genomic-coordinate token in beta_units.tsv is excluded from this display. All displayed start/end coordinates satisfy 1 <= start <= end <= source length.

All 239 proteins were scanned uniformly with HMMER 3.4 hmmscan against Pfam-A.hmm (SHA256 `6dd422355e2c1b99619fd8704aa7fc0ab455af6778a304068af08b803d68c6b8`), `--domE 1 --incdomE 1 --noali --cpu 2`. The broad output retains weak candidate calls; the producer keeps other Pfam domains at conditional E < 1e-3 and applies the S3 tree-usable PF01453 recovery rule uniformly: independent E <= 1, HMM coverage >= 0.5 and envelope length >= 40 amino acids. Calls overlapping more than half the shorter aligned region are resolved by lowest conditional E value. The result contains 667 architecture blocks across all 246 tips, including 61 PF01453 blocks above the strict membership cutoff (independent E > 1e-5). All Pfam/CBM calls are preserved in the TSV; the figure distinguishes B-lectin, GH30, PI-PLC-X and other common domains, with remaining Pfam classes shown as Other Pfam. The scan output is a domain annotation, not evidence that a protein lacks any function when no domain passes this sensitivity threshold.

The GH30_3 reference panel has exact PF01453 B_lectin calls in eight displayed tip rows (R001–R007 and R010) from seven distinct source proteins; R010 also contains GH30 and PI-PLC-X. These counts agree with the corrected historical inventory. The uniform scan, applied to references and cynipoids alike, is the architecture display authority.
